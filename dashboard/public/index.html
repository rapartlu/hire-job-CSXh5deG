Authentication

        

          Paste your Deliveroo Bearer token below. To get it: open deliveroo.co.uk in your browser,
          open DevTools → Network, reload the page, click any /consumer/graphql
          request, and copy the Authorization header value (starts with Bearer eyJ).
          Tokens expire; refresh if you get auth errors.

One-time setup

        
    
          
  1. 
            Download the CA cert
            
    ⇓ mitmproxy-ca-cert.pem
    
            
    The cert is generated when the proxy first starts. If this gives a 404, wait a few seconds and try again.
    
          
    2. 
          
  2. 
            Install in Chrome
            
    Go to chrome://settings/security → Manage certificates → Authorities → Import → select the .pem file → tick "Trust this certificate for identifying websites".
    
          
    3. 
          
  3. 
            Install in Firefox
            
    Preferences → Privacy & Security → Certificates → View Certificates → Authorities → Import → select the .pem file → tick "Trust this CA to identify websites".
    
          
    4. 
          
  4. 
            Configure browser proxy
            
    Set HTTP proxy to 127.0.0.1, port 8080.
    
            
    Chrome: Settings → System → Open your computer's proxy settings. Firefox: Preferences → Network Settings → Manual proxy → HTTP proxy = 127.0.0.1, port 8080, also use for HTTPS.
    
          
    5. 
          
  5. 
            Browse Deliveroo
            
    Open deliveroo.co.uk and search for restaurants or dishes. Traffic appears in the Live feed tab above.
    
          
    6. 
          
  6. 
            Export for analysis
            
    After a few searches, go to the Export tab and download the CSV. Attach it to the GitHub issue for Milestone 2.
    
          
    7. 
        

        
⚠ Session tokens and responses are stored in a local SQLite file on your machine. Nothing is sent anywhere outside your machine. The proxy captures and stores locally only.
